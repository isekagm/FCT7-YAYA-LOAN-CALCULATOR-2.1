YAYA TRUST FUND LOAN MANAGEMENT SYSTEM V2.1

V2.1 corrects the JavaScript syntax error that prevented navigation and button actions in V2.0.

DEPLOYMENT
1. Extract this ZIP.
2. Replace every file in the GitHub repository root with these files.
3. Commit the changes to main.
4. After GitHub Pages redeploys, perform a hard refresh (Ctrl+Shift+R).
5. If an old service worker remains, open Chrome DevTools > Application > Service Workers > Unregister, then refresh.

Files: index.html, app.js, manifest.json, sw.js, icon.svg, README.txt.
